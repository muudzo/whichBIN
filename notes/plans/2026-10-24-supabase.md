# Plan: Supabase connection (24 Oct 2026)

**Jira:** SCRUM-51 (tables, insert-only rules, stats), SCRUM-52 (save every answer), SCRUM-53 ("x of y got this wrong too"), SCRUM-54 (privacy line). Built from the two diagrams in `design/architecture/`.

## Decisions (agreed 24 Oct)

| Question | Decision |
|---|---|
| Who writes the SQL | **I write it, Claude coaches** with a quick lesson (`supabase/README.md`) and tests written first (`supabase/tests/permissions.sql`) |
| How the counts work | **Counted when asked**: database functions count the answers; browsers never read individual answers |
| Who decides right or wrong | **The database**: an `items` table (item → bin), filled from `app/src/data/items.json`, and the counts compare each answer with it |
| How SQL reaches Supabase | **Connection string in `supabase/.env`** (git-ignored). Claude applies the SQL and runs the tests with psql; the tests run in a transaction that is undone, so they leave no rows |
| Players table from the diagram | **Dropped**: a player is only the random session id per visit, already on every answer |
| City requests (SCRUM-51, SCRUM-52) | **Dropped**: the city screens were cut |
